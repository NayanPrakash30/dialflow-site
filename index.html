How it works
  1. Paste your list. One number per line — or paste a whole block of text, DialFlow picks out the numbers.
  2. Set the gap. 3, 5 or 10 seconds between calls, or type your own.
  3. Press Start and put the phone down. Each row updates live: pending, calling, in call, called or skipped.

Install help

Android will ask you to allow installing apps from this source the first time:

  1. Tap Download APK above and open the file.
  2. When prompted, allow your browser to install unknown apps (Settings → Apps → your browser → Install unknown apps).
  3. If Play Protect warns you, tap More details → Install anyway. The SHA-256 above is the exact file we publish — you can verify it.
  4. Open DialFlow and grant Phone permission. That is what lets the app place calls and know when one has ended.

DialFlow asks for permission to make calls and read the call state only. It has no access to your contacts, call log or recordings, and it never uploads your numbers anywhere.

Questions
Does the app read my call log or contacts?

No. It reads only the live call state (idle, ringing, off-hook) so it knows when a call has finished and the next one can be placed. No contacts, no call log, no recordings, nothing sent to us.

What happens when the 24-hour trial ends?

The Start button stops working and the app asks for a licence key. Your number list and settings are kept. Paste a key and everything continues as before.

Can I use one key on two phones?

No — a key is bound to the device code it was issued for. Message us and we can move your licence to a new phone if you replace the old one.

Is anything charged automatically?

Never. You pay once per period, by UPI, and then a key is issued manually. There is no auto-renew and we never see your bank or UPI credentials.

Refunds?

A licence key is delivered digitally and immediately, so payments cannot be refunded once the key has been issued. If your key does not work we will fix or replace it — just message us.

Which phones are supported?

Any Android 8.0 (Oreo) or newer device. Dual-SIM phones work too.

Privacy policy

No account, no sign-up, no tracking. Everything you enter — your number list, settings, trial state and licence — is stored only on this device. Nothing is uploaded to us. During a dial session the app reads the phone's call state (idle / ringing / off-hook) so it knows when to place the next call. Payments are made in your own UPI app, directly to our UPI ID. We never see your card, bank or UPI credentials. Uninstalling the app deletes all of this data.
